# 两个模拟案例 · Two simulation cases

这里保存 `scripts/simulation_workflow.R` 生成的 **seed 4** 数据，用于学习导入和模拟，不是论文的原始调查观测。
These **seed 4** files are generated by `scripts/simulation_workflow.R` for import and simulation lessons; they are not empirical observations from the paper.

| 案例 / Case | 时间步 / Step | 生成路径 / Dynamics | 文件 / Files |
|---|---|---|---|
| [flatfish](flatfish) | 年度 / Annual | 年龄型 / Age-based | 三张 CSV 与 truth.rds / Three CSV files and truth.rds |
| [tuna](tuna) | 季度 / Quarterly | 年龄与长度联合 / Joint age-length | 三张 CSV 与 truth.rds / Three CSV files and truth.rds |

`truth.rds` 保存 `parameters` 和 `truth`，用 `readRDS()` 读取。这里的时间标签从 2000 开始，只作教学示意。完整模拟参数可以从保存对象读取，不需猜测单位或默认值。
`truth.rds` contains `parameters` and `truth`; read it with `readRDS()`. Time labels starting at 2000 are illustrative. Inspect saved parameters for the complete generator configuration.

```r
# 从仓库根目录运行 / Run from the repository root
library(ALSCL)
flatfish_inputs <- read_survey_csv("docs/data/cases/flatfish")  # 读取时检查表格 / tables are checked on reading
tuna_inputs <- read_survey_csv("docs/data/cases/tuna")
tuna_example <- readRDS("docs/data/cases/tuna/truth.rds")
str(tuna_example$parameters)
```

flatfish 预设的调查 SD 为 0.2，与主要绘图数据 `YTF_example`（沿用 YTF 的 0.1）不同。不要将这两个对象混称为同一份数据。
The flatfish preset survey SD is 0.2, unlike the main plotting dataset `YTF_example`, which retains YTF's 0.1. These are distinct datasets.
