- `structure` 新增第五项设置 `correlation_range`，ACL 和 ALSCL 都可使用。`"positive"`（默认）使补充量和 F 的 AR(1) 相关系数在 0 和 1 之间，是 `logit_*` 参数的 logistic 变换。`"symmetric"` 使相关系数在 -1 和 1 之间（2 * logistic - 1），因此相关系数为零在数值检查中不再是边界，也可以估计负相关。`"symmetric"` 下相关系数 rho 在优化器尺度上为 `qlogis((rho + 1) / 2)`；默认起点保持原来的自然尺度取值，`inspect_parameters()`、`extract_parameters()`、`profile_model()` 和 `simulate_fit()` 使用同一变换。补充量没有自相关或呈负自相关时请使用它：默认范围下这样的拟合会落到下界，无法通过数值检查。
- `structure` 可以取一组设置的名称：`"original"` 或 `"von_bertalanffy"`。`"original"` 是默认结构，即本包最初发布时的结构，它实现了 Zhang 和 Cadigan (2022) 的模型。它的生长增量有两处细节只在代码里，论文没有给出：logistic 增量等于最大值 50% 和 95% 时的体长（0.5 Linf 和 0.05 Linf），以及增量乘以时间步长。`"von_bertalanffy"` 同时选用 `growth_increment = "von_bertalanffy"`、`growth_transition = "bin"`、`initial_length = "growth"` 和 `initial_plus_group = "equilibrium"`（ACL 只有 plus group 一项）。列表可以先指定一组设置再追加，例如 `list(set = "von_bertalanffy", correlation_range = "symmetric")`。`"published"` 和 `"consistent"` 是 `"original"` 和 `"von_bertalanffy"` 以前的名称，仍然可以使用。四项设置要一起使用：在季度时间步、组宽 5 cm 的模拟检验中，只用其中一部分的拟合不能通过数值检查或有很大偏差。`"von_bertalanffy"` 也是单项设置 `growth_increment` 的一个取值：`structure = list(growth_increment = "von_bertalanffy")` 只改一项，`structure = "von_bertalanffy"` 四项都改。ALSCL 拟合的 `structure` 列表只改了四项中的一项、两项或三项时，拟合给出一条提示，列出仍为原始取值的设置（`silent = TRUE` 时不显示；`fit_scenarios()`、`hindcast_model()` 和 `retro_model()` 每次调用只提示一次）。先指定这组设置再替换其中一项的列表，例如 `list(set = "von_bertalanffy", growth_transition = "midpoint")`，不给提示。`growth_transition = "midpoint"` 下，如果生长在 Linf 估计值的 90% 以下停止（个体每个时间步留在某个体长组的概率不低于 0.99），`run_alscl()` 给出提示，`summary()` 也会显示，拟合结果中保存 `growth_check`。不能通过梯度检查的拟合（最大梯度分量不低于 0.001）会再做一轮精修。这一轮在目标函数的上升不超过其计算精度时接受能降低梯度的步长；似然在某个参数方向上非常陡时需要这样做，例如 von Bertalanffy 增量下的 Linf。第一轮之后已通过梯度检查的拟合不变。
- `run_alscl()` 和 `retro_model()` 新增参数 `t0_lower`（默认 0）。ALSCL 使用 t0 = t0_lower + exp(log_t0)，因此可以固定或估计负的 t0，例如设 `t0_lower = -1` 和 `parameters = list(log_t0 = log(t0 + 1))`。报告的 t0 在自然尺度上。在数据包中请把它存在 `fit_config$alscl` 之下。
- ALSCL 的年龄别 F 现在覆盖每个年龄（包括 plus group）和每个时期：`extract_estimates(fit, "FA")`、不带区间的 `plot_fishing_mortality(type = "age")` 以及 `plot_compare_F_ts(basis = "age")` 都如此。拟合报告（`fit$report$FA`）没有变化，包含 plus group 之前的年龄和最后一期之前的时期，并带有标准误；其余单元格按同一公式由报告的体长—年龄别尾数算出，没有标准误，因此带区间的图只显示报告中的单元格。`extract_estimates()` 把 FA 的末期各行标为 `extrapolated`。最后几期没有正的调查观测时，从最后一个有观测的时期起的 F 和渔获量也会被标记。

- `run_acl()`、`run_alscl()`、`retro_model()`、`hindcast_model()`、`fit_scenarios()`、`refit_model()` 和输入列表中的自然死亡率和调查可捕性可以取更多形式。不使用这些形式的拟合结果不变。`M` 可以是一个数，一个每个年龄组一行、每个时间步一列的矩阵（或只有一列并用于所有时间步），或者（仅 ALSCL）每个体长组一个值的数值向量。后两种形式由 `dim` 属性区分：不随时间变化的年龄别 M 写作 `matrix(M_at_age, ncol = 1)`。ALSCL 中 M 按年龄或按体长给出时，年龄别 F 等于年龄别总死亡率减去 M 按体长别尾数加权的平均值，`ZL` 等于体长别 F 加上 M 按年龄别尾数加权的平均值，报告以 `M_LAY` 保存所用的死亡率。新增 `lorenzen_M()`，按 `M_ref * (length / L_ref)^exponent` 返回按体长的 M，默认指数为 -1（Lorenzen 2022；Lorenzen 等 2022）。新增参数 `survey_q`，直接给出调查可捕性：按体长的向量，或按体长和时间步的矩阵（例如用于调查网具更换之后），用来代替 `sel_L50` 和 `sel_L95`（这两个参数现在默认为 `NULL`）；两者同时给出会报错。新增 `survey_catchability()`，为 `survey_q` 计算 logistic 和穹顶形曲线。新增参数 `survey_q_age`，是按年龄的调查可捕性系数；给出它时，`mean_log_R` 的默认初值提高 `-log(survey_q_age[1])`。`project_model()` 接受按年龄的未来 M；拟合的 M 随时间变化时必须给出。`summary()` 和 `print()` 指出非默认的输入形式。`plot_compare_selectivity()` 绘制给定的可捕性。模拟函数仍只使用单一的 M，并在报错中说明。M、`survey_q` 和 `survey_q_age` 都是假定：调查指数不能把总死亡率分成捕捞死亡率和自然死亡率，也不能确定调查可捕性的水平和下降段。

- `run_acl()`、`create_parameters()` 和 `retro_model()` 新增参数 `bounds = c("default", "wide")`。`"wide"` 让 ACL 的下列参数采用 ALSCL 的边界：初始总死亡率（上界由 1 改为 10）、平均捕捞死亡率（由 1 改为 2）、初始年龄别尾数和补充量的标准差（由 1 改为 10），以及 von Bertalanffy 生长率 k（由每年 0.1 到 1 改为 0.05 到 2）。默认边界不变。ACL 拟合停在某个默认上界时，提示中会指出这个参数；t0 停在上界时，提示中会说明这个上界的含义。
- 新增用于把拟合与年龄鉴定资料和外部评估相比较的输出，都由拟合结果或保存的结果算出。`length_at_age()` 返回每个年龄组和时间步的平均体长及标准差，分种群口径和调查口径（体长别尾数乘以体长别调查可捕性）。比较生长时请用它：在 ALSCL 中，Linf、k 和 t0 决定体长别生长增量和补充个体的体长，不是各年龄平均体长的 von Bertalanffy 曲线参数。`ssb_at_age()` 按年龄别成熟比例（向量，或按年龄和时间步的矩阵）和年龄别生物量返回产卵生物量，并同时给出模型按体长别成熟比例算出的 SSB；可以给出各年龄的平均体重。`relative_catch()` 返回尾数和重量计的渔获量除以其在各时间步上的均值；只拟合调查数据时，渔获量和 F 的绝对水平无法确定，它们取决于所假定的自然死亡率和调查可捕性，所以只应把趋势与上报渔获量比较。`compare_models()` 的输出有变：`growth` 把参数按模型各列成一组行并注明含义（列为 Model、Parameter、Estimate、Meaning），不再是每个模型一列；新增元素 `length_at_age`，给出两次拟合各年龄的平均体长；`correlation` 中渔获量的两行标为 "CN (relative)" 和 "CB (relative)"，没有 `Ratio_Mean`；现在包含 ACL 拟合的重量计渔获量。
- 文档：模型原理一文新增“包与论文的差别”一节，说明 F 过程和补充量过程的边际标准差（Zhang 和 Cadigan 2022 的式 7 用的是创新方差）、默认固定的 F 过程标准差、logistic 生长增量的两个体长、增量乘以时间步长，以及初始年龄别尾数的偏差沿年龄累积。各篇文章、函数参考和手册说明了以上五项中的输入、检查和输出，并指出只拟合调查数据时 F 的水平取决于所假定的自然死亡率和调查可捕性。

- `sim_acl()` 将每次重复的结果（包括失败状态）保存到 `result_rep_<iter>`。复用输出目录时，本轮失败记录会替换旧成功结果；汇总前检查 `converge` 和 `error`。写入失败会明确报告，不能视为已经保存。`simulation_to_tables(sm, pa)` 使用模拟结果的长度坐标，并拒绝与参数不一致的坐标，不再给观测重新贴错标签；没有坐标的旧模拟可使用匹配的参数元数据。
- `create_parameters(species = "krill", model_type = "acl")` 提供 Linf 初值 90 和边界，不会自动固定 Linf，也不更改 M、nage 或时间步长。需要固定时，显式传入 `map = list(log_Linf = factor(NA))` 和选定初值；生物设置仍需在拟合参数中提供。
- 两个编译模型在极小总死亡率下稳定计算 Baranov 渔获比例，与模拟器一致，避免相减抵消为零；普通量级结果仅可能在浮点精度上变化。

- 标准误计算结束后，返回的可执行 TMB 对象会恢复到最终拟合参数。在拟合所在的 R 会话中，`fit$obj$report()` 与 `fit$report` 因此描述同一个拟合状态，包括顺序计算及并行失败后的回退。已保存的估计值和标准误不因此改变。序列化保存的结果仍需重新拟合后才能使用可执行 TMB 对象。
- `plot_compare_residuals()` 和 `plot_compare_CatL()` 除时间及体长元数据外，也核对已知观测值及正观测掩码。请传原始拟合表；修改数值或将缺失单元改为观测会报错。没有保存观测的旧结果仍可使用，但无法完整核验观测匹配。比较图的观测点排除零值和 NA，与拟合约定一致；这些位置仍可显示预测曲线。
- 完整模拟保留真实零值和极小正调查观测，不再把小于 `1e-6` 的值替换为 `1e-6`。调查生物量等于调查尾数乘以重量，零资源情形也保持一致。只有原先触发下限的新模拟数据会变化，旧保存数据不改写。拟合规则不变：`zero_action = "missing"` 将零视为缺失，`"error"` 拒绝零值；全零调查没有正观测，不能使用当前对数正态模型拟合。
- 模拟体长中点必须落在对应组内，检查规则与拟合一致；首尾组仍吸收分布尾部。参数准备阶段会拒绝无效分组，生物量计算和模拟前还会再次检查，包括用户手动修改的输入；错误发生在随机抽样和写文件前。
- 已验证的 TMB 版本为 1.9.21 和 1.9.25。现有 Windows、macOS、Linux 检查已在 1.9.25 上通过两模型、两种 AD 框架的严格并行一致性测试，不允许用单核回退代替通过；Windows 使用 socket，并跳过 Unix fork 测试。其他 TMB 版本继续使用顺序计算保护。这扩大了可启用加速的版本范围，不保证小模型也会提速；实际方法请看 `fit$sd_info`。

## ALSCL 2.1.0

### 各系统上的速度设置

标准误现在在 Windows 以及 RStudio、R.app、Positron 中也能使用多个核：当 delta 方法预计超过约 3 秒时，由 socket 进程计算，结果逐位相同。每次拟合在 `fit$sd_info` 中记录标准误的计算方式，`alscl_speed_info()` 显示设置在本机上的实际效果。新增的[速度设置](../articles/speed.html)一文详细说明每项设置。

### 速度设置

新增 `alscl_speed()`，用于设置拟合时标准误的计算方式。默认在单次拟合内用多个核计算标准误，结果与 ALSCL 2.0.0 逐位相同；基准测试中拟合快 1.13-1.24 倍。`alscl_speed(framework = "TMBad")` 改用 TMB 的 TMBad 库编译模型，拟合快 1.25-1.68 倍，但估计值与默认设置略有差异。参见 [`alscl_speed()` 函数参考](../reference/alscl_speed.html)。

### 并行拟合更新

`run_acl()` 与 `run_alscl()` 新增 `nstarts`，可以将总起点数与 `ncores` 并行进程数分开设置，保留原有默认行为。返回诊断包含实际 PID 与 CPU 时间。参见[并行性能实测](../articles/reproducibility.html)中的相同工作量计时和可复现证据。
